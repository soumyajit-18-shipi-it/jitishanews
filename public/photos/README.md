# HER PHOTOGRAPHS DIRECTORY

Place her real photographs here!

For example:
- `portrait-1.jpg`
- `portrait-2.jpg`
- `portrait-3.jpg`
- `portrait-4.jpg`
- `portrait-5.jpg`
- `portrait-6.jpg`

Then in `src/config/princessData.ts`, update the corresponding `url` field:
```typescript
{
  id: "portrait-1",
  url: "/photos/portrait-1.jpg",
  // ...
}
```

The gallery will immediately display her real photo with:
- Natural aspect ratio preservation
- Full-screen high-resolution lightbox
- Zero facial modification (her natural beauty, skin tone, and features are completely preserved)
